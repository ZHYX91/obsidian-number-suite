# 编号、题注与交叉引用：进阶说明

[返回简体中文 README](i18n/README.zh-CN.md)

## 让正文标题显示简短序号

打开**显示与外观 → 虚拟标题序号格式**，把“正文标题”设为“仅显示当前级”，方案中的 `1.2.3.4.5` 就会显示为 `5`。大纲和标题思维导图默认跟随正文。指向标题的链接和引用默认显示方案中的完整序号，即使正文中有两个标题都显示为 `5`，读者也能从引用中分清它们。三个位置均可独立选择。原本只显示一级的方案会保留自身写法，例如 `第３章`。

这些选项仅影响虚拟标题序号。笔记中已有的序号保留原文，写入、重新编号和语义导出继续使用这篇笔记的编号方案。

## 罗马数字范围与批量恢复

按文件夹批量处理时，预览只扫描所选文件夹及其子目录中的 Markdown 文件，并跳过排除目录及其内容。选择全库范围可以预览所有符合条件的 Markdown 文件。

罗马数字模板支持 1–3999。预览检查全部待生成的标题，包括后续递增和模板引用的父级计数。任一罗马数字计数越界时，写入和重新编号均保持整个文件不变，并提示调整起始值或格式。清理操作仍可使用。纯显示编号会省略不可用的标签，不再显示十进制回退值。

批量处理或撤销失败后，恢复先前写入的步骤也可能失败。结果会分别报告已恢复、恢复失败和结果未确认的文件数量，并列出需要检查的文件。在存储允许时保留既有恢复数据；未确认保存恢复记录时会另行提示。请保留副本并核对受影响文件后，再尝试撤销上次批量处理。并发编辑会保留，因此不能把部分恢复当作全部恢复成功。

## H7-H9 扩展标题

Number Suite 与 DocWen 共享一套明确的 Word 7～9 级标题扩展：行首精确写 7、8 或 9 个
`#`，随后至少一个空白字符。10 个及以上井号仍是普通文本。扩展标题参与编号、起始值、重置、
排除、写入、Live Preview、阅读视图，以及只读的 `number-suite.interop.v2` 消费者快照。

H7-H9 不是 Obsidian/CommonMark 原生标题层级。Number Suite 增强原生大纲并按源码行跳转；其他宿主标题索引仍可能无法识别。互通与引用时建议写入稳定块 ID，例如 `######## 深层主题 ^deep-topic`。需要阅读视图
增强时，每个扩展标题应单独成段，并在前后留空行。纯显示使用始终以 Markdown 源码为准且
不修改源码。

## 题注与对应对象

题注与交叉引用显示从不写入 Markdown。题注必须是以 `Figure:`、`Table:`、`Equation:` 或
`Code:` 精确开头的顶层段落；`Listing:` 不是兼容别名。识别出的整条题注显示为实心胶囊，
可选编号位于胶囊内部。普通 Wiki 标题链接默认不增强；可独立开启同文件编号显示，保留原生交互。
在**题注 → 题注计数范围**中选择**整篇笔记**或**按章节重新计数**。选择后者时会出现“章节标题级别”，初始为 H1。若选 H2，1.2 节的第一幅图显示为 **Figure 1.2-1**，在 1.3 节引用它也显示同一编号。图、表、公式、代码分别计数。正文或大纲使用短标题编号时，题注仍显示完整的章节前缀。

遇到同级或更高级标题，前一节结束。章节前缀采用标题编号方案的完整格式，并遵循单篇笔记的起始编号。标题正常计数但没有显示模板时，使用本级的数字。所选级别的空标题、排除标题、跳过或无法编号的标题也会结束上一节。未归入可编号章节的题注在本篇共用各类型自己的无前缀计数。嵌入笔记按自己的源文计数。已有的 v2 互操作导出仍提供整篇笔记内的题注序号。

题注关键词只决定语义标签和编号系列，相邻的独立块决定实际承载结构。因此任意题注类型都可
绑定图片、Markdown 表格、块公式或围栏代码块；例如 `Figure:` 可为包含多张图片的表格提供图题，
而表格仍保持原生表格结构。题注与对象之间最多留一个空行；留两个空行即可分开。两侧都有候选对象或同一对象
有多个候选题注时失败关闭。未绑定题注仍继续编号、显示胶囊并可被交叉引用。
题注对齐独立于题注编号。Figure 和 Equation 默认居中；可在“题注”选项卡中分别调整四种
固定题注类型。
每种类型还可以单独选择视觉上位于“对象上方”或“对象下方”，四种类型均默认在上方。题注与
对象之间的小间距只属于显示效果，切换位置不会改写文件。Live Preview 中光标进入题注时，胶囊
消失，并在规范源码位置显示完整的 `Figure: ... ^id`；编辑某个交叉引用时，也只展开该引用自身
的 `@[[...]]` 源码。源码模式始终显示原文。触控与输入法编辑也只显露当前标题、题注或引用的源码，其他虚拟序号与胶囊保持可见。

在编辑模式中，可右键独占一行的 `![[image.png]]` 或 `![alt](image.png)` 图片添加 Figure
图名；右键顶层 Markdown 表格任意一行添加 Table 表名；右键独立 `$$...$$` 块公式添加
Equation 公式名；右键顶层围栏代码块添加 Code 代码名。操作使用真实右键目标，图片不需要先被
选中。如果 Live Preview 中的表格已由 Structural Tables 接管，同一个表名操作也会加入它的
渲染表格右键菜单，包括普通表格接管和多行结构表头。操作前会核对文件、表格原文和精确位置。旧版 Structural Tables 未提供这些信息，或表格语法暂不支持时，菜单会显示停用说明；此时请在源码模式中手动添加或编辑题注。两个插件也可以独立使用。

弹窗会先预览将写入的精确 Markdown 行，再通过一次有界编辑器事务执行。所有新题注都存放在
对象上方；紧邻图片下方的旧 Figure 题注会提供有界的“移到上方”操作。如果相邻关键词仅大小写
有误（例如 `figure:`），同一操作会修正它，而不是插入重复题注。已有精确题注、笔记嵌入、行内
图片、行内公式、行内代码，以及表格单元格里的图片/公式/代码都不会出现独立题注操作；交叉引用
仍可写在单元格里。创建题注不会创建块 ID。移动或修正已有题注时，会保留它的行内和后续独立块 ID，原有块引用仍指向这条题注。

“显示图片与图题悬停提示”默认开启。悬停绑定 Figure 的图片或图题，都会看到渲染图题及有效的
Wiki 替换文字或 Markdown alt；两者相同时只显示一次，文件名和 `500`、`500x300` 尺寸值不会
制造提示。行内或单元格图片可以只显示替换文字，但仍不能拥有独立 Figure 题注。

## 同文件交叉引用

打开 **设置 → Number Suite → 交叉引用**，开启**显示同文件交叉引用**。在同文件目标链接
前加上 `@`。标题名唯一时可直接引用标题；题注名唯一时可用包含固定类型的完整题注名引用。
目标有编号时会带上编号，但关闭标题序号和题注编号后，引用胶囊仍然显示。

```markdown
## 安装

请参见 @[[#安装]] 或 @[[#安装|安装章节]]。

Figure: 系统架构 ^fig-architecture

请参见 @[[#Figure: 系统架构]] 或 @[[#^fig-architecture|系统架构图]]。
```

如果标题显示为 `1`、题注显示为 `Figure 1: 系统架构`，以上引用胶囊分别显示为
`1 安装`、`1 安装章节`、`Figure 1: 系统架构` 和 `Figure 1: 系统架构图`。关闭编号后，
这些引用仍是胶囊，只是不再带编号。标题的虚拟序号使用紧凑实心胶囊，题注目标使用实心
胶囊，交叉引用使用可交互描边胶囊，因此目标与链接不只依赖颜色区分。

可读的手写引用使用 `@[[#标题]]`，或使用 `@[[#Figure: 系统架构]]` 这样的完整题注名。
标题名和题注名在同一个文件内共同消歧；精确目标为零或多个时保持原样。不带固定类型的名称
只按标题解析。以后编辑造成重名时，Number Suite 不会自动改写已有题名引用。

需要稳定引用时，在标题或题注上右键选择**复制交叉引用**。目标已有唯一块 ID 时会按原始大小写直接复用并
复制，包括隔一个空行的独立 ID。同一目标有多个 ID 或同一 ID 归属多个目标时拒绝操作；没有 ID 时先预览一个有界 Markdown 改动，确认后才创建 ID。题注 ID 追加在题注行末，标题
ID 使用合法的下一行独立块 ID，然后复制带可读别名的链接。这是题注与交叉引用流程中唯一会
创建 ID 的显式操作。普通 Wiki 标题链接默认不增强；开启选项后，`[[#标题]]` 和带文件名的同文件 `[[笔记#标题]]` 在实时预览和阅读视图增加纯显示编号，保留别名和原生交互。跨文件、块引用、嵌入、普通 Markdown 链接及缺失或有歧义目标保持原样。单击显式引用可跳转；F2 或移动端源码编辑入口可编辑原文。

## 脚注与尾注

类型化注释显示同样不修改 Markdown。`[^id]` 和 `[^footnote:id]` 属于脚注，显示为
`1、2、3`；`[^endnote:id]` 属于尾注，显示为 `E1、E2、E3`。两种计数器在每个文件内分别
从 1 开始，并按首次引用顺序编号；重复引用复用首次编号。

“脚注与尾注”设置选项卡可以让 Live Preview 保留原始标记，或用格式化编号替换。采用
格式化编号时，单击显示编号或把光标移到编号处，即可展开并编辑实体标记。阅读模式继续保留
带编号的原生跳转。定义缺失、重复、冲突或渲染不匹配时保持 Obsidian 原样。采用两个空格
缩进的多行注释正文不会进入标题、题注或语义引用扫描。

## 原生大纲与结构编辑

先启用 Obsidian 核心“大纲”插件；Number Suite 不自动开启，未启用时提供指引。功能区直接打开“当前笔记”，在 Obsidian 的“大纲”中浏览标题。“当前笔记”有“显示与编号”和“修改正文”两个标签。原有快捷键和已保存的工作区仍可打开对应面板。

“常规”提供默认开启的“增强原生大纲”总开关；关闭撤销增强与导图入口并保留偏好，不自动启用核心大纲。工具栏的“显示选项”包含标题编号、无编号时显示标题级别、H7–H9、题注四项，跨面板统一持久保存且只影响大纲；已有关闭值保持不变。标题的虚拟编号用浅强调色实心胶囊，仍可见且符合描边范围的实体编号用独立实线或虚线胶囊，两者可同时出现。没有任何可见编号且启用层级显示时，才使用中性 H1–H9 胶囊，悬停说明编号来源或级别。题注保留类型图标、本地化序号及次级标题，无胶囊或展开箭头。原生导航与正文有效编号规则保持不变。

H7–H9 仅在同父同级标题之间拖动完整章节，包含正文、题注和子标题，落点标记显示目标。源文变化则拒绝写入，单次有界编辑器事务支持原生撤销与重做。题注不能独立拖动，H1–H6 原生操作保持可用。

原生大纲工具栏和“当前笔记”标题栏按自己面板的源文件打开导图，焦点切换不改变绑定；命令入口跟随活动笔记。导图默认只浏览，显式开启“调整结构”后支持同父同级整节拖动和“章节上移/下移”按钮，无效落点不写入。**视图 → 允许拖拽改变标题的父章节**默认关闭。开启后，拖到标题中央可移入，拖到边缘可插入其前后，落点标记会预览目的地。选中标题后，键盘和触摸用户也可用**移动章节**选择目标标题，查看可用落点后再应用。所移子树的内部层级保持一致，必要时调整标题级别。写入要求匹配的 Markdown 编辑器和未变化快照，保留原有编号及链接文本。


### 实体编号与普通 Wiki 标题链接的显示规则

在「标题编号」中禁用内置方案后，自动描边和隐藏立即停止使用该方案的模板。重新启用即可恢复识别。当前选中的方案决定生成编号的格式，所有已启用的方案都可以识别笔记中的已有编号。其他方案、插件标记或单独开启的手写识别仍可能匹配同一个前缀。笔记属性中已指定的方案保留其编号格式，并在「当前笔记」中标明禁用状态。手动发起并预览的清理仍能识别历史格式。

在「标题编号」中，「已有标题编号的描边范围」位于「已有序号识别范围」之后。选项为「关闭」、「仅匹配方案或带插件标记的编号」（默认）和「也包含常见手写编号」。仍可见的编号若匹配方案或带有 Number Suite 标记，使用透明底实线胶囊。选择最广范围后，仅由常见手写规则识别、中等及以上置信度的可见前缀也使用透明底虚线胶囊。可疑的年份、版本号、计量数字和低置信度前缀保留纯文本。隐藏范围单独设置，因此隐藏匹配方案的编号时，仍可为可见的手写编号描边。虚拟编号用实心强调色胶囊，可以与已有编号同时显示，数值相同时也各自保留。实时预览、阅读视图、原生大纲和导图遵循相同规则，并为悬停和辅助技术提供类型提示。源码模式不为已有编号描边。Markdown、清理范围和题注样式保持原样。

开启虚拟编号后，只要标题算出了编号，即使原有前缀仍然可见，也会显示虚拟编号。
如果想隐藏二级标题中形如 `1) ` 的常见手写前缀，开启「隐藏已写入序号」，
然后在「已有序号识别范围」选择「也隐藏常见手写编号」。

只想调整一篇笔记时，在「当前笔记 → 显示与编号 → 已写入编号」选择「隐藏」，即可设置「隐藏范围」。选「继承全局」会使用全局识别范围，即使全局未开启隐藏。其余选项只影响当前笔记，并在 `number-suite` 列表里保存 `heading.hide-stored-scope=plugin`、`heading.hide-stored-scope=templates` 或 `heading.hide-stored-scope=common`。已有笔记若没有这条指令，就继承全局范围。选择「显示」或继承全局可见性会暂时停用已保存的范围，再次选择「隐藏」时恢复。此范围与描边和清理范围独立。

普通同文件 Wiki 链接增强仍默认关闭。开启后，**只有目标标题实际显示虚拟编号**，才在原生链接前添加无焦点、不可独立点击的中性灰编号胶囊；不拿实体编号或 H 级别充当虚拟编号。显式 `|别名` 的原有文字完全保留，即便别名带数字也不去重。不带别名时，若启用了“隐藏已写入序号”，仅将可靠识别的实体前缀从链接**可见文字**中隐藏；链接目标、右键、修饰键点击、悬停及 Markdown 原文不变。实时预览和阅读模式共用这一规则；带路径但解析到当前文件的链接可以增强，跨文件、块链接和嵌入保持原生。无法可靠识别时不隐藏、不猜测。显式 `@[[...]]` 始终保留完整引用胶囊，不拆成左右两段。

公文方案前四级写作 `一、总体要求`、`（一）指导思想`、`1.工作目标` 和 `（1）具体措施`。旧笔记在序号后留有空格也能识别。启用公文方案后，`# 一、标题` 和 `## 一、 标题` 都可以给 `一、` 加实线描边。多个层级匹配同一段前缀时优先采用标题自身的层级。跨级识别保留 Markdown 标题层级，单凭跨级命中不能删除序号或重编号。

自定义模板末尾显式输入的空格会原样写入。识别时，这类模板要求序号和正文之间至少有一个横向空白，支持普通空格、全角空格和制表符。例如，在 `{1.chinese_lower}、` 后输入一个空格，模板就能识别 `一、 标题`，而 `一、二、三` 不符合它的条件。其他启用的方案或常见手写规则仍可能识别这段前缀。纯数字格式保留分隔。紧排的点号遇到数字开头的标题时也需要分隔，以免形成小数，例如公文方案给 `2项措施` 加上序号后会写成 `1. 2项措施`。

启用公文方案、虚拟编号为 `1` 时，两种编号都显示会得到实心的 `1` 和原文 `一、标题`。隐藏已有序号后，留下实心的 `1` 和 `标题`。关闭虚拟编号时，两种情况下都只留下可见原文。无别名的原生 Wiki 链接遵循目标标题的隐藏设置，保留原链接目标。
