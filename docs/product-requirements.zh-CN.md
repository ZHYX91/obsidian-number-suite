# Number Suite — 产品需求

[English synced translation](product-requirements.md)

<!-- section: authority -->
## 文档权威性

本文是 Number Suite 产品需求的中文规范源。英文文件是同步译本。实现、测试或其他文档与
本文冲突时，应先更新中文规范源、评审差异，再同步英文；执行证据不能修改产品要求。

<!-- section: purpose -->
## 产品目的

Number Suite 让用户分别控制“标题序号是否写入 Markdown”和“标题序号是否在 Obsidian
中可见”。插件必须允许用户保持纯净源文件、保存实体序号、隐藏实体序号或以计算序号替换其
视觉呈现，同时保持标题变换可预览、可解释并尽量可恢复。用户明确修改按笔记设置时，Properties 另外保存，并显示保存状态。

<!-- section: users-and-jobs -->
## 用户与核心任务

- 只想在 Obsidian 中看到层级序号、但不想污染 Markdown 的用户。
- 需要向其他工具输出带实体序号 Markdown 的用户。
- 已有实体序号，希望临时隐藏或安全清理的用户。
- 需要公文、法律条文或自定义层级格式的用户。
- 需要对当前笔记、文件夹或整个库执行一致操作的用户。

<!-- section: scope -->
## 范围

产品处理顶层原生 ATX H1-H6 标题及精确的 Number Suite/DocWen H7-H9 扩展，并支持实时预览、
阅读视图、当前笔记写入操作、批处理、内置及自定义方案、精确标题排除、按笔记 Properties
覆盖、纯显示题注编号、脚注/尾注编号、同文件
语义交叉引用、增强的 Obsidian 原生 H1-H9 与题注大纲，以及 12 种受支持的界面语言。标题方案、每种题注计数、脚注/尾注计数和引用解析都以单个
Markdown 文件为作用域；嵌入文件仍按自己的源码与设置处理。

<!-- section: functional-requirements -->
## 功能要求

1. 虚拟显示和视觉隐藏不得修改 Markdown。
2. 写入、清理、重新编号和移除来源标记必须先生成不可变预览计划。
3. 虚拟显示、阅读视图和文件修改必须共享同一编号语义。
4. 空 Hn 模板不输出序号，但仍增加计数、重置后代并参与后代模板。
5. 非空 Hn 模板必须包含本层占位符，且不能引用后代层级。
6. 自定义方案修改或删除前的模板必须可用于识别历史插件序号，直至用户明确清除历史。
7. 精确排除不得使用模糊或正则匹配；排除标题不得占用计数。
8. 未触碰的笔记不得被写入插件 Properties。按笔记覆盖统一使用一个 `number-suite` 文本列表，
   以规范的 `path=value` 指令记录停用状态、虚拟显示、隐藏已有序号、方案、H1-H9 首个显示数字
   及 H1-H9 开头跳过数；恢复继承会移除对应指令。旧字段保持只读兼容；新旧等价值可读取，
   冲突、重复、未知指令、无效值及不可用方案均失败关闭。“当前笔记”中的明确修改可以只迁移
   该笔记且保留无关 Properties；清理范围属于操作预览选择，不属于笔记元数据。
9. 首个显示数字与开头跳过数是彼此独立的逐级语义。skip-first 按整篇文件中各级非空标题的
   源码顺序计数，并包含被方案排除的标题；被跳过的标题不消耗计数器，也不会隐式跳过后代。
10. 只有顶层 `Figure:`、`Table:`、`Equation:` 和 `Code:` 段落声明题注；不兼容
    `Listing:`。四种类型在每个 Markdown 文件内分别从 1 开始，无论是否存在块 ID 都编号，
    显示路径不得写入实体题注编号。无论编号是否开启，识别出的整条题注都使用实心胶囊。
    四种固定类型分别具有独立居中开关，题注编号关闭时仍可
    生效；Figure 和 Equation 默认开启，Table 和 Code 默认关闭并跟随主题。题注类型只决定
    语义标签和编号，不限制承载对象类型；任意题注可绑定一个相邻的独立图片、表格、块公式或
    围栏代码块。零或一个空行允许绑定，两个空行解除绑定；题注或对象存在多个候选时失败关闭。
    未绑定声明仍是题注。原生表格正文即使没有管道符仍属于表格；紧跟表格行的题注近似文本
    必须用一个空行与表格分开才成为题注。四种类型还可分别显示在绑定对象上方或下方，默认均在上方且不改写
    源码；对象锚点提供统一的紧凑视觉间距。图片/Figure 悬停提示默认开启，
    将渲染图题与有效替换文字分开显示，并去重、排除尺寸值和仅文件名噪声。
11. 只有显式 `@[[#目标]]`、`@[[#^块ID]]` 及其可选 Obsidian 别名请求同文件语义增强。
    目标可以是唯一标题名，也可以是 `Figure: 系统架构` 这样的唯一完整类型化题注名。标题名
    和题注名共同消歧；零个或多个匹配都失败关闭。可见编号存在时带上编号，但编号不是前提。 普通同文件 Wiki 标题增强独立默认关闭；开启后支持实时预览、阅读视图与带文件名的同文件目标，保留别名及原生交互，不扩大到跨文件、块、嵌入和普通 Markdown 链接。显式引用单击跳转，提供 F2 和移动端可访问的源码编辑入口。
12. 显示路径和题注创建不得创建或改写 ID。只有显式的**复制交叉引用**右键操作可以复用
    目标已有块 ID，或在精确预览和源码过期校验后，用一次编辑器事务在目标合法 Markdown 位置
    创建块 ID。题注 ID 位于题注行末；标题 ID 可以使用下一行独立块 ID。已有独立 ID 允许隔一个空行，复用时保留原始大小写；同一目标有多个 ID 或同一 ID 归属多个目标时不得自动新增或任选一个 ID。
    后续编辑造成歧义时，不迁移或自动改写已有题名引用。
13. `[^id]` 和 `[^footnote:id]` 声明脚注，`[^endnote:id]` 声明尾注。脚注与尾注在每个
    Markdown 文件内分别从 1 开始，按首次引用顺序编号，重复引用复用首次编号。脚注显示
    纯数字，尾注显示 `E` 前缀。
    普通正文中的脚尾注和语义引用标记遵循 Markdown 反斜杠奇偶规则：连续奇数个反斜杠转义
    标记，偶数个仍使标记有效。代码、HTML 和链接目标等受保护区域仍独立排除。
14. 脚注/尾注显示不得创建、重命名或重写定义、引用、ID 或其他 Markdown。缺失定义、重复
    定义、默认与显式脚注的规范化 ID 冲突，以及源码与渲染结果数量不一致时均失败关闭。定义
    的两空格或 Tab 缩进续行属于受保护容器，不得被扫描为标题、题注或语义引用。Live Preview
    可显示格式化编号或原始标记；单击格式化编号或把光标移到编号处会展开可编辑标记，阅读
    模式保留原生跳转。
15. H7-H9 只识别顶层、行首精确 7、8 或 9 个井号且随后有空白的源码行；10 个及以上井号
    仍是普通文本。扩展标题共用九级解析、计数器、模板、Properties 起始值、变换和
    `number-suite.interop.v2` 语义。已有六项模板的自定义方案升级后 H7-H9 保持为空。
    原生大纲由插件增强以显示扩展层级；反向链接、标题路径导航和其他宿主标题索引仍不承诺识别扩展层级；
    互通目标建议使用用户已有的稳定块 ID。
16. 功能区图标直接打开常驻右侧栏的“当前笔记”，其中有“显示与编号”和“修改正文”两个标签；文档导航由 Obsidian 的“大纲”提供。旧命令、快捷键与工作区状态应迁移兼容。“常规”提供默认开启的“增强原生大纲”总开关；关闭撤销增强与导图入口并保留偏好，不自动启用核心大纲。工具栏的“显示选项”包含标题编号、无编号时显示标题级别、H7–H9、题注四项，跨面板统一持久保存且只影响大纲；已有关闭值保持不变。标题的虚拟编号用浅强调色实心胶囊，可靠识别且未隐藏的实体编号用独立细描边胶囊；两者可同时出现。没有任何可见编号且启用层级显示时，才使用中性 H1–H9 胶囊，悬停说明编号来源或级别。题注保留类型图标、本地化序号及次级标题，无胶囊或展开箭头。原生导航与正文有效编号规则保持不变。不得自动开启核心大纲插件，未启用时给出操作指引。保留原生折叠、筛选、当前位置跟随、多面板与固定文件行为，不修改正文或共享 metadata cache。标题使用小编号胶囊与文字；题注使用类型图标、本地化类型序号和次级文字，整条不套胶囊，按所属章节内源码位置排列并作为无展开箭头的叶子。计数与正文有效编号一致，不受筛选或折叠影响，也不重复存储编号。H7-H9 支持同父同级完整章节拖动排序，包含正文、题注和子标题，显示明确落点，拒绝过期源文并支持完整 Undo/Redo；不得改父级、级别或独立拖动题注，不得全局禁用 H1-H6 原生拖动。导图从原生大纲工具栏、“当前笔记”和命令进入，面板入口绑定自己的源文件；显式结构编辑模式复用有界不可变计划和安全写入校验，支持同父同级整节拖动及上下移动按钮。

17. 编辑器右键菜单只为独占一行的图片嵌入、顶层 Markdown 表格、独立块公式和顶层围栏代码块
    提供题名插入。Figure、Table、Equation、Code 题注统一存放在对象上方；紧邻图片下方的旧
    Figure 题注提供有界迁移。真实右键目标优先于编辑器光标；行内及单元格内图片、公式、代码
    不得成为独立题注目标。Structural Tables 接管的 Live Preview 渲染表格通过
    自己的菜单提供同一操作，并核对带版本的文件路径、精确原文及 UTF-16 范围；表格序号不能作为写入目标，不能确定映射时失败关闭。相邻关键词仅大小写错误时修正原行而不重复插入。
    每次操作都必须经过题名预览、不可变有界计划、精确源码复核和一次编辑器事务；不支持、
    受保护、已过期、有歧义或已经有题注的目标均失败关闭；任意语义类型的相邻题注都表示该
    承载对象已有题注。
18. 标题虚拟序号使用紧凑实心胶囊，整条题注使用可换行实心胶囊，增强后的交叉引用使用可
    键盘聚焦的交互式描边胶囊；目标与引用同时通过填充和边框区分，而不是只依赖颜色。

行内代码、行内数学、块公式内部及有效 Markdown 链接的目标和标题不声明题注、语义引用或脚注，包括支持的跨物理行范围；保护精确到源码范围，同一行范围外的正文及链接可见文字中的标记仍可识别。无效或未闭合的链接近似文本不因括号形状被遮蔽。转义、未闭合或内侧紧邻空白的美元符号仍是普通正文。合法 GFM 表格数据行先归属表格，即使分隔单元格只有一个或两个连字符、省略边界管道或第一格以题注关键词开头，也不得迁出或改换为题注。此保护不扩大题注菜单支持的承载对象范围。公式的外部载体与其内部保护资格相互独立。

<!-- section: safety-requirements -->
## 安全要求

- 对小数、版本、年份、日期和单位数量等歧义前缀默认失败关闭。
- 写入不得静默覆盖未确认的人工序号。
- 当前笔记确认前必须复核文件、视图和预览源内容。
- 批处理必须复核全部目标内容、保存有界恢复数据，并在并发冲突时停止而不是覆盖。
- 来源标记必须默认关闭，并提供保留可见序号的移除路径。
- 插件不得包含联网、遥测、广告或远程资源。
- 实体标题变化可能破坏标题链接；插件必须提示风险，不得猜测重写链接。

- 卸载后停止新的批处理及撤销正向写入。已派发的宿主写入需要结算，精确补偿可继续但不得覆盖后续编辑；新启用的实例须等待旧操作结算后再取得恢复记录所有权。

<!-- section: non-goals -->
## 非目标

- 不支持正文内局部方案切换，也不支持已冻结 H7-H9、题注、脚注/尾注和显式语义引用声明
  之外的用户自定义控制语法。
- 不自动重写标题链接、嵌入或外部锚点。
- 不解析跨文件语义引用。
- 不承诺 Setext、Canvas、Backlinks、Search Results 或 PDF 导出集成；Obsidian 原生大纲增强属于范围内功能。
- 不把自动测试、模拟器记录或构建成功表述为所有宿主平台验收。

<!-- section: acceptance -->
## 产品验收

每项需求必须有纯逻辑或适配层测试；涉及真实 Obsidian UI、IME、移动端、主题或生命周期的
声明还必须使用精确候选在隔离 Vault 中取得证据。源码检查、候选包检查、桌面与 Android 模拟器
验收和公开发布状态必须分别判断。Android 真机和 iOS 不在验收范围内。详细规则见
[测试策略](testing-strategy.zh-CN.md)。公开发布由本仓库工作流执行，并需要明确授权。


### 实体编号与普通 Wiki 标题链接的显示规则

全局“描边显示正文已有编号”位于“标题编号”下、“隐藏已写入序号”附近，默认开启，不增加笔记级 YAML 设置。关闭隐藏时，仅将可靠识别的正文标题编号描边显示；可疑年份、版本号、低置信度数字和普通段落数字一律保持原文。源码模式及 Markdown 从不改写。虚拟编号使用浅强调色填充，实体编号用透明细描边，二者同时显示时分成两个胶囊，即使数字相同也不去重。原生大纲和导图沿用这一区分；Hn 是中性层级提示，正文题注保持原样。

普通同文件 Wiki 链接增强仍默认关闭。开启后，**只有目标标题实际显示虚拟编号**，才在原生链接前添加无焦点、不可独立点击的中性灰编号胶囊；不拿实体编号或 H 级别充当虚拟编号。显式 `|别名` 的原有文字完全保留，即便别名带数字也不去重。不带别名时，若启用了“隐藏已写入序号”，仅将可靠识别的实体前缀从链接**可见文字**中隐藏；链接目标、右键、修饰键点击、悬停及 Markdown 原文不变。实时预览和阅读模式共用这一规则；带路径但解析到当前文件的链接可以增强，跨文件、块链接和嵌入保持原生。无法可靠识别时不隐藏、不猜测。显式 `@[[...]]` 始终保留完整引用胶囊，不拆成左右两段。

虚拟编号、隐藏已写入序号的四种组合，以及按模板识别时的空格要求，见[进阶指南](advanced.zh-CN.md#实体编号与普通-wiki-标题链接的显示规则)。
