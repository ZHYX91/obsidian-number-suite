# Number Suite

Number Suite показывает номера заголовков, подписей, ссылок, сносок и концевых примечаний в Obsidian. Для показа на экране менять Markdown не нужно. Запись номеров в файл запускается отдельно.

## Начало работы

1. В **Настройки → Number Suite → Нумерация заголовков** включите **«Показывать виртуальные номера»**.
2. Откройте режим предварительного просмотра или чтения. Номера появятся рядом с заголовками, а исходный текст останется прежним.
3. Чтобы записать номера в Markdown, откройте текущую заметку на боковой панели Number Suite. Выберите запись или перенумерацию, проверьте предварительный просмотр и подтвердите.

## Подписи и ссылки

Над изображением, таблицей, отдельной формулой или блоком кода добавьте строку с `Figure:`, `Table:`, `Equation:` или `Code:`. Ключевые слова пишутся по-английски. Подписи могут показывать номер. Ссылки внутри заметки используют `@[[#Заголовок]]`; обычные `[[#...]]` не меняются. Сноски `[^id]` и концевые примечания `[^endnote:id]` нумеруются отдельно.

```markdown
Figure: Architecture

![[architecture.png]]
```

## Схемы нумерации и сохранность текста

Доступны иерархическая схема, примеры для китайских официальных и юридических документов и варианты с традиционными китайскими, японскими, корейскими и арабско-индийскими цифрами. Смена языка интерфейса не меняет выбранную схему. Выбор схемы сам по себе не меняет Markdown. Запись, удаление и перенумерация заголовков, создание подписей и идентификаторов ссылок могут изменять файл. Проверьте изменения и сохраните резервную копию: прежние ссылки на заголовки могут сломаться. Уровни 7–9 — расширенный синтаксис.

## Установка и помощь

Требуется Obsidian 1.12.7 или новее на компьютере или Android; iOS пока не проверен. Установите плагин из каталога сообщества или скопируйте `main.js`, `manifest.json` и `styles.css` из одного выпуска в `.obsidian/plugins/number-suite/`. Плагин работает локально, без телеметрии. Подробнее см. [английское руководство](../../README.md).
