# Number Suite

[English](../../README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Español](README.es.md) · [Português (Brasil)](README.pt-BR.md) · [Русский](README.ru.md) · [Tiếng Việt](README.vi.md) · [العربية](README.ar.md)

Number Suite는 Obsidian의 제목, 캡션, 참조, 각주와 미주에 번호를 표시하는 플러그인입니다. 번호를 화면에만 표시하면 Markdown 원본은 변경되지 않습니다. 파일에 번호를 쓰는 작업은 별도로 실행합니다.

이 문서는 자주 쓰는 기능을 다룬 **간단한 안내서**입니다. H7–H9, 캡션과 대상의 연결, 안정적인 참조, 각주에 관한 자세한 내용은 [영문 고급 안내](../advanced.en.md) 또는 [중국어 간체 고급 안내](../advanced.zh-CN.md)를 참고하세요.

<!-- section: installation -->
## 설치

Obsidian 1.12.7 이상이 필요합니다. 데스크톱과 Android를 지원하며 iOS 동작은 아직 확인하지 않았습니다.

1. Obsidian의 설정 → 커뮤니티 플러그인 → 탐색에서 Number Suite를 찾아 설치하고 활성화합니다.
2. 수동으로 설치하려면 [GitHub Releases](https://github.com/ZHYX91/obsidian-number-suite/releases)에서 버전 ZIP을 내려받아 압축을 푼 `number-suite` 폴더를 `.obsidian/plugins/`에 넣습니다. 같은 릴리스의 `main.js`, `manifest.json`, `styles.css`를 `.obsidian/plugins/number-suite/`에 넣어도 됩니다.
3. Obsidian을 다시 불러오고 플러그인을 활성화합니다. 서로 다른 버전의 파일을 섞지 마세요.

<!-- section: quick-start -->
## 시작하기

1. **설정 → Number Suite → 제목 번호**에서 ‘가상 번호 표시’를 켭니다.
2. 라이브 미리 보기 또는 읽기 화면을 엽니다. 제목 옆에 번호가 나타나지만 노트 내용은 그대로입니다.
3. 번호를 파일에 저장하려면 오른쪽 Number Suite 패널에서 현재 노트를 선택한 다음 번호 쓰기 또는 다시 매기기를 실행하세요. 미리 보기를 확인한 뒤 적용합니다.

현재 노트의 표시 및 파일 작업 안내에서 원문, 목표, 작업을 비교할 수 있습니다. 노트별 표시 설정은 Properties에 저장되지만 표시 자체는 제목을 다시 쓰지 않습니다. 미리 보기는 파일별로 접혀 있으며 변경과 경고 수를 보여 줍니다. 펼친 뒤 더 불러오기를 눌러 전체 결과를 확인하세요. 플러그인을 끄면 일괄 처리나 실행 취소의 새 쓰기는 중단되지만 이미 요청한 쓰기는 완료될 수 있습니다. 안전하게 되돌릴 수 없으면 플러그인 폴더의 `recovery.json`을 보존하고 먼저 노트를 확인하세요.

## 캡션과 참조

이미지, 표, 독립 수식 또는 코드 블록 위에 `Figure:`, `Table:`, `Equation:`, `Code:` 중 하나로 시작하는 캡션 줄을 추가하세요. 이 키워드는 영어 그대로 써야 합니다. 캡션 번호는 화면에만 표시할 수도 있습니다. 같은 노트 안의 참조는 `@[[#제목]]`을 사용합니다. 일반 `[[#제목]]` 링크는 변경되지 않습니다. 각주 `[^id]`와 미주 `[^endnote:id]`는 따로 번호를 매깁니다.

```markdown
Figure: Architecture

![[architecture.png]]
```

캡션을 옮기거나 키워드의 대소문자를 고칠 때 기존 인라인 및 독립 줄의 블록 ID도 캡션과 함께 유지됩니다. 기존 블록 참조는 같은 캡션을 가리킵니다.

## 번호 형식과 파일 보호

기본 계층 번호와 중국 공문서·법률 문서 형식, 번체 중국어·일본어·한국어·아라비아-인도 숫자 형식 예시를 제공합니다. 인터페이스 언어를 바꿔도 번호 형식이 자동으로 바뀌지 않습니다. 형식을 선택하는 것만으로 파일이 수정되지는 않습니다. 번호 쓰기·삭제·다시 매기기나 캡션, 참조 ID 만들기는 Markdown을 변경할 수 있습니다. 제목 링크가 끊어질 수 있으니 미리 보기를 확인하고 백업하세요. 7~9단계 제목은 확장 문법입니다.

<!-- section: settings -->
## 설정 위치

전체 설정의 일곱 탭은 일반, 제목 번호, 캡션, 상호 참조, 각주와 미주, 번호 기록 및 정리, 표시와 일괄 처리입니다. 인터페이스 언어와 번호 형식은 따로 선택합니다. 오른쪽 사이드바의 현재 노트에서 한 노트만 설정할 수 있습니다. 전체 설정 따르기로 되돌리면 해당 재정의만 제거되고 다른 Properties는 그대로 남습니다. 문서 개요와 읽기 전용 제목 마인드맵에서 원문으로 이동할 수도 있습니다.

<!-- section: limitations -->
## 지원 범위와 제한

- Markdown 파일 하나에 번호 규칙 하나를 사용합니다. 캡션 번호와 상호 참조도 같은 파일 안에서 처리합니다.
- 목록, 인용문, 코드 예제, HTML 블록, frontmatter 안의 제목과 캡션은 문서 번호에 포함하지 않습니다. 일반 목록 텍스트의 각주와 상호 참조는 사용할 수 있습니다.
- Structural Tables의 표는 파일, 원문, 위치를 확인할 수 있을 때 캡션 작업을 제공합니다. 이전 버전이나 지원하지 않는 표에서는 비활성 안내가 표시됩니다. 이때는 소스 모드에서 캡션을 직접 추가하거나 편집하세요.
- H7–H9는 Number Suite와 DocWen의 확장 문법입니다. Obsidian 기본 개요나 제목 링크가 이를 인식하지 못할 수 있으므로 안정적인 참조에는 블록 ID를 사용할 수 있습니다.

<!-- section: privacy-and-support -->
## 개인정보와 도움말

플러그인은 로컬에서 실행되며 네트워크 통신이나 사용 정보 수집을 하지 않습니다. 번호 표시만으로 노트를 수정하지 않습니다. 쓰기, 지우기, 다시 번호 매기기는 미리보기를 확인한 뒤 적용하세요. 제목 텍스트를 바꾸면 기존 제목 링크에 영향을 줄 수 있습니다. 문제를 보고할 때는 버전, 재현 단계, 개인 정보가 없는 최소 Markdown 예제를 포함해 주세요.
