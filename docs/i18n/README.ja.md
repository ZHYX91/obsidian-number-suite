# Number Suite

[English](../../README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Español](README.es.md) · [Português (Brasil)](README.pt-BR.md) · [Русский](README.ru.md) · [Tiếng Việt](README.vi.md) · [العربية](README.ar.md)

Number Suite は Obsidian の見出し、キャプション、参照、脚注、文末脚注に番号を表示するプラグインです。画面に番号を表示するだけなら Markdown は変更されません。ファイルへの書き込みは別の操作です。

<!-- section: installation -->
## インストール

Obsidian 1.12.7 以降が必要です。デスクトップと Android に対応し、iOS の動作は未確認です。

1. Obsidian の「設定 → コミュニティプラグイン → 閲覧」で Number Suite を検索し、インストールして有効にします。
2. 手動の場合は [GitHub Releases](https://github.com/ZHYX91/obsidian-number-suite/releases) からバージョン付き ZIP を取得し、展開した `number-suite` フォルダーを `.obsidian/plugins/` に置きます。同じリリースの `main.js`、`manifest.json`、`styles.css` を `.obsidian/plugins/number-suite/` に置く方法も使えます。
3. Obsidian を再読み込みして有効にします。異なるバージョンのファイルを混ぜないでください。

<!-- section: quick-start -->
## 使い始める

1. **設定 → Number Suite → 見出し番号** で、「仮想番号を表示」をオンにします。
2. ライブプレビューか閲覧ビューを開きます。見出しの番号は表示されますが、ノートの本文はそのままです。
3. 番号を Markdown に保存する場合は、右側の Number Suite パネルで現在のノートを選び、書き込みまたは振り直しを実行します。プレビューを確認してから確定してください。

<!-- section: captions -->
## キャプションと参照

画像、表、独立した数式、コードブロックの上に `Figure:`、`Table:`、`Equation:`、`Code:` で始まる行を書きます。キーワードは英語のまま使います。キャプションには画面上で番号を付けられます。同じノートの見出しやキャプションへの参照は `@[[#見出し]]` と書きます。通常の `[[#見出し]]` リンクは変わりません。脚注 `[^id]` と文末脚注 `[^endnote:id]` は別々に番号が付きます。

```markdown
Figure: Architecture

![[architecture.png]]
```

キャプションを移動したりキーワードの大文字・小文字を修正したりしても、既存の行内・独立行のブロック ID はキャプションと一緒に保持されます。ブロック参照の対象は変わりません。

<!-- section: numbering -->
## 番号形式とファイルの安全性

階層番号のほか、公文書・法律文書向けの形式例、繁体字中国語・日本語・韓国語・アラビア・インド数字の形式例があります。表示言語を変更しても番号形式は自動では変わりません。形式を選ぶだけでは本文も変わりません。一方、番号の書き込み・削除・振り直し、キャプションや参照 ID の作成はファイルを変更する場合があります。見出しへのリンクが切れるおそれがあるため、プレビューとバックアップを確認してください。見出しレベル 7〜9 は拡張記法です。

<!-- section: settings -->
## 設定の場所

全体設定は一般、見出し番号、キャプション、相互参照、脚注と文末脚注、ファイル操作、表示に分かれています。言語と番号形式は別々に選びます。右サイドバーの「現在のノート」で個別設定を変更でき、「全体設定に従う」に戻すとその上書きだけが消えます。他の Properties は変わりません。文書アウトラインと読み取り専用の見出しマインドマップから元の行へ移動できます。

<!-- section: limitations -->
## 対応範囲と制限

- 番号形式は Markdown ファイルごとに一つです。キャプションの番号と相互参照も同じファイル内で扱います。
- リスト、引用、コード例、HTML ブロック、frontmatter 内の見出しやキャプションは文書の番号に含めません。通常のリスト本文にある脚注や相互参照は使えます。
- Structural Tables の表では、ファイル・原文・範囲を確認できる場合にキャプション操作を表示します。古いバージョンや未対応の表では操作が無効になり、理由を表示します。その場合はソースモードで手動編集してください。
- H7–H9 は Number Suite と DocWen の拡張です。Obsidian 標準のアウトラインや見出しリンクでは認識されない場合があります。安定した参照にはブロック ID を使えます。

<!-- section: privacy-and-support -->
## プライバシーとサポート

プラグインはローカルで動作し、通信やテレメトリー収集を行いません。番号の表示はノートを変更しません。書き込み・削除・振り直しはプレビューを確認してから実行します。見出しの文字列を変えると既存のリンクに影響する場合があります。問題の報告にはバージョン、手順、個人情報を含まない最小の Markdown 例を添えてください。
