# Number Suite

[English](../../README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Español](README.es.md) · [Português (Brasil)](README.pt-BR.md) · [Русский](README.ru.md) · [Tiếng Việt](README.vi.md) · [العربية](README.ar.md)

Number Suite は Obsidian の見出し、キャプション、参照、脚注、文末脚注に番号を表示するプラグインです。画面に番号を表示するだけなら Markdown は変更されません。ファイルへの書き込みは別の操作です。

このページは日常操作向けの**簡易ガイド**です。H7–H9、キャプションの対応付け、安定した参照、脚注の詳細は[英語の上級ガイド](../advanced.md)または[簡体字中国語の上級ガイド](../advanced.zh-CN.md)を参照してください。

<!-- section: installation -->
## インストール

Obsidian 1.12.7 以降が必要です。デスクトップと Android に対応し、iOS の動作は未確認です。

1. Obsidian の「設定 → コミュニティプラグイン → 閲覧」で Number Suite を検索し、インストールして有効にします。
2. 手動の場合は [GitHub Releases](https://github.com/ZHYX91/obsidian-number-suite/releases) からバージョン付き ZIP を取得し、展開した `number-suite` フォルダーを `.obsidian/plugins/` に置きます。同じリリースの `main.js`、`manifest.json`、`styles.css` を `.obsidian/plugins/number-suite/` に置く方法も使えます。
3. Obsidian を再読み込みして有効にします。異なるバージョンのファイルを混ぜないでください。

**手動更新：** 既存のプラグインフォルダー内の `main.js`、`manifest.json`、`styles.css` だけを、同じリリースのファイルで置き換えてください。設定を保持するため、`data.json` は残してください。`recovery.json` や `recovery.pending.json` がある場合も残してください。一括処理の取り消し・復元データが保存されているため、更新時に上書きや削除をしないでください。

<!-- section: quick-start -->
## 使い始める

1. **設定 → Number Suite → 見出し番号** で、「仮想番号を表示」をオンにします。
2. ライブプレビューか閲覧ビューを開きます。見出しの番号は表示されますが、ノートの本文はそのままです。
3. 番号を Markdown に保存するには、**現在のノート → 本文を編集** で書き込みまたは振り直しを選び、プレビューを確認してから適用します。

ノートごとの表示設定は Properties に保存されますが、表示自体は見出しを書き換えません。プレビューはファイルごとに折りたたまれ、変更数と警告数が表示されます。展開して追加読み込みすると全件を確認できます。無効化するとバッチ処理や取り消しの新たな書き込みは止まりますが、送信済みの書き込みは完了する場合があります。安全に戻せない場合は、プラグインフォルダーの `recovery.json` を残し、先にノートを確認してください。

現在のノートはファイル名、自動状態、3つの主要設定をコンパクトに表示し、保存済みの表示は場所を取りません。保存中とエラーは表示します。単一ノートへの書き込み、振り直し、番号やマーカーの削除はサイドバー内のプレビューに切り替わり、対象を固定して戻る・キャンセル・適用を提供します。ノートを切り替えても対象は変わらず、ソース変更時はプレビューを作り直します。バッチは幅広のダイアログを使います。構造調整ではモード名、移動ボタン、対象の強調と前後の挿入線を表示し、無効な対象や利用できないソースの理由を示します。

## キャプションと参照

画像、表、独立した数式、コードブロックの上に `Figure:`、`Table:`、`Equation:`、`Code:` で始まる行を書きます。キーワードは英語のまま使います。キャプションには画面上で番号を付けられます。同じノートの見出しやキャプションへの参照は `@[[#見出し]]` と書きます。見出しやキャプション自体のブロック ID は `@[[#^block-id]]` で参照できます。通常の段落ブロックへのリンクには Obsidian 標準の動作が適用されます。脚注 `[^id]` と文末脚注 `[^endnote:id]` は別々に番号が付きます。

```markdown
Figure: Architecture

![[architecture.png]]
```

キャプションを移動したりキーワードの大文字・小文字を修正したりしても、既存の行内・独立行のブロック ID はキャプションと一緒に保持されます。ブロック参照の対象は変わりません。

<!-- section: numbering -->
## 番号形式とファイルの安全性

階層番号のほか、公文書・法律文書向けの形式例、繁体字中国語・日本語・韓国語・アラビア・インド数字の形式例があります。表示言語を変更しても番号形式は自動では変わりません。形式を選ぶだけでは本文も変わりません。一方、番号の書き込み・削除・振り直し、キャプションや参照 ID の作成はファイルを変更する場合があります。見出しへのリンクが切れるおそれがあるため、プレビューとバックアップを確認してください。見出しレベル 7〜9 は拡張記法です。

<!-- section: settings -->
## 設定の場所

一括処理の設定は「**書き込みと整理**」、リンクの設定は「**リンクと参照**」、番号の外観は「**表示と外観**」にあります。


全体設定は7タブです。「一般」の標準アウトライン拡張は既定でオンです。オフにしても設定を保持し、コアのアウトラインを自動で有効にしません。アウトラインの表示メニューでは番号、番号がない見出しのレベル、H7–H9、キャプションを共有設定として保存します。本文やマップには影響しません。計算した番号は塗りつぶし、見出しに書かれた番号は表示対象なら枠線付きで表示します。両方を同時に表示でき、番号がなければ見出しレベル（Hn）を表示できます。現在のノートでは仮想番号、保存済み番号の表示、番号形式を個別に継承・上書きし、状態を表示します。開始・スキップ規則は折りたたみ、必要なレベルだけ追加します。無効化しても設定を保持し、書き込みと整理にはプレビューが必要です。マップの葉には0を表示せず、配置と展開深度は副メニューにあります。移動ボタンと挿入先は構造調整モードのみ表示します。

標準アウトラインと現在のノートから、そのペイン自身のファイルのマップを開けます。「構造を調整」で、同じ親・同じレベルの節全体をドラッグまたは上下ボタンで移動できます。変更済みのソースは拒否し、元に戻す・やり直すに対応します。明示的な参照は1クリックで移動し、F2またはモバイルのソース編集操作で編集します。同じファイル内の通常のWiki見出しリンクの番号表示は既定でオフです。任意に有効化すると、ファイル名付きも含めプレビュー・閲覧画面で使え、別名と標準操作を保持します。

H2 から採番する形式で開始番号を 4 にした場合、`heading.skip-first.h2=1` はノート全体で最初の空でない H2 を、`heading.skip-per-parent.h2=1` は各 H1 の下で最初の H2 を選びます。両方に該当する節は配下の見出しごと一度だけスキップします。最初の H1 の下で次の H2 は `4`、その最初の H3 は `4.1` になります。H1 はノート全体でのみ数えます。「ルールを削除」で、そのレベルの設定をすべて解除できます。

両方のルールが元の並び順で数え、スキップした節内の見出しも数に含めます。直上のレベルがない場合は最も近い上位見出しを親とし、上位見出しがなければノートのルートを使います。

<!-- section: limitations -->
## 対応範囲と制限

- 番号形式は Markdown ファイルごとに一つです。キャプションの番号と相互参照も同じファイル内で扱います。
- リスト、引用、コード例、HTML ブロック、frontmatter 内の見出しやキャプションは文書の番号に含めません。通常のリスト本文にある脚注や相互参照は使えます。
- Structural Tables の表では、ファイル・原文・範囲を確認できる場合にキャプション操作を表示します。古いバージョンや未対応の表では操作が無効になり、理由を表示します。その場合はソースモードで手動編集してください。

<!-- section: privacy-and-support -->
## プライバシーとサポート

プラグインはローカルで動作し、通信やテレメトリー収集を行いません。番号の表示はノートを変更しません。書き込み・削除・振り直しはプレビューを確認してから実行します。見出しの文字列を変えると既存のリンクに影響する場合があります。問題の報告にはバージョン、手順、個人情報を含まない最小の Markdown 例を添えてください。
