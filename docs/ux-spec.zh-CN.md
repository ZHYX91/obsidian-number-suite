# Number Suite — 交互规范

[English synced translation](ux-spec.md)

<!-- section: authority -->
## 文档权威性

本文是交互与文案行为的中文规范源；英文文件为同步译本。视觉截图和执行证据不覆盖本文。

<!-- section: principles -->
## 交互原则

- 始终区分源文件状态和 Obsidian 中的视觉状态。
- 标题变换前必须先让用户看到逐项结果和风险；明确修改笔记 Properties 时直接保存，并显示持久化状态。
- 默认选项应保守，歧义情况应保留原文并给出原因。
- 全局值、当前笔记覆盖值和最终生效值必须可区分。
- 移动端、窄窗口、键盘和触摸操作必须保持可达，不依赖悬停。

<!-- section: entry-points -->
## 入口

功能区图标直接打开常驻右侧栏的“当前笔记”。旧大纲命令与工作区状态迁移兼容。原生大纲工具栏和当前笔记标题栏提供绑定源文件的思维导图入口，命令入口跟随活动笔记。命令面板还提供恢复
源样式、独立切换虚拟显示/隐藏、当前笔记写入/清理/重新编号、移除来源标记、批处理和撤销最近批处理。
没有活动 Markdown 笔记时，当前笔记操作不可执行并显示明确提示。

<!-- section: current-note-panel -->
## Number Suite 侧栏

## 原生大纲与结构编辑

先启用 Obsidian 核心“大纲”插件；Number Suite 不自动开启，未启用时提供指引。功能区直接打开“当前笔记”，旧“文档大纲”已移除；旧命令、快捷键与工作区状态迁移兼容到现有入口。

“常规”提供默认开启的“增强原生大纲”总开关；关闭撤销增强与导图入口并保留偏好，不自动启用核心大纲。工具栏的“显示选项”包含标题编号、无编号时显示标题级别、H7–H9、题注四项，跨面板统一持久保存且只影响大纲；已有关闭值保持不变。标题的虚拟编号用浅强调色实心胶囊，仍可见且符合描边范围的实体编号用独立实线或虚线胶囊，两者可同时出现。没有任何可见编号且启用层级显示时，才使用中性 H1–H9 胶囊，悬停说明编号来源或级别。题注保留类型图标、本地化序号及次级标题，无胶囊或展开箭头。原生导航与正文有效编号规则保持不变。

“显示与外观”把虚拟标题序号格式集中在一组。正文标题、指向标题的链接和引用默认按编号方案显示，大纲和标题思维导图默认跟随正文。三个位置均可选择只显示当前级。信息按钮支持悬停、键盘和触屏点击，说明这些选项的适用范围。

H7–H9 仅在同父同级标题之间拖动完整章节，包含正文、题注和子标题，落点标记显示目标。源文变化则拒绝写入，单次有界编辑器事务支持原生撤销与重做。题注不能独立拖动，H1–H6 原生操作保持可用。

原生大纲工具栏和“当前笔记”标题栏按自己面板的源文件打开导图，焦点切换不改变绑定；命令入口跟随活动笔记。导图默认只浏览，显式开启“调整结构”后支持同父同级整节拖动和“章节上移/下移”按钮。移动会跨越或改变 Markdown 章节边界时，按钮和拖放目标都会说明原因。无效落点不写入，在放开后保留简短本地化原因；取消和无变化不误报错误。“调整结构”有明确文字状态，移动按钮直接可见，目标高亮与前后插入线指明落点。写入要求匹配的 Markdown 编辑器和未变化快照，不改级别、不重写编号、不重定向链接。桌面和 Android 触摸拖动须独立提供真实宿主证据，按钮可用不能代替拖动证据。

标题思维导图把 H1-H9 标题连接到虚拟文件根节点。根节点显示不含扩展名的文件名、文件图标
和直接顶层标题数量，不显示标题序号；无标题时也保留，不与同名 H1 合并。所有没有父标题
的标题都挂在文件根下，包括开头的 H2。根卡片主体导航到文件顶部。快速连续定位时，光标落在最后选择的位置。复制交叉引用时使用菜单或确认按钮所在窗口的剪贴板。子树范围以所选标题为根，
上方文件名入口返回整篇文档。初次以 100% 缩放显示前两层实际标题结构，更深分支默认折叠。
点击缩放百分比恢复 100%。这些显示规则不会修改 Markdown，也不会在后续编辑时重置展开状态。

图谱只投影标题，不显示题注，也不把题注计入子标题数量。默认从左到右布局：
每个标题是一张卡片，父标题的右侧连接到子标题左侧。左把手优先显示当前实际可见的虚拟序号；
若没有虚拟序号而存在可见且符合描边范围的实体序号，则按识别类型以实线或虚线显示实体编号；两者同时可见时并列两个独立胶囊；都没有时显示中性 Hn。右侧箭头显示直接子标题总数，点击仅展开或折叠该分支；叶子不显示箭头或 0。跳级标题直接归入最近的更浅标题，不生成虚构中间节点。

思维导图支持整篇文档和“所选标题子树”两个范围、一次显示 1/2/3 层或全部结构层级、
从左到右/从上到下两种布局、标题/序号搜索、Fit、空白区域平移、Ctrl/Cmd+滚轮围绕指针缩放，
以及双指捏合缩放。搜索命中时可以临时展开必要祖先，但不改变持久的结构计数或用户折叠意图；
清空搜索后恢复会话内折叠状态。搜索框中按 Enter 与 Shift+Enter 按文档顺序前后遍历命中项，
并显示当前/总命中数。若选中的命中标题重新隐藏，则选择其最近的可见祖先，并保持它在原命中
卡片的屏幕位置。单击卡片选择，双击卡片或在卡片主体上按 Enter 跳到精确源码行。编辑当前文档
时可以刷新图谱内容，但不得因此重置同一文档的选择、折叠和视口。默认浏览不写入；显式“调整结构”模式支持同父同级整节拖动及上下移动，使用不可变预览计划、过期校验和单次编辑器事务，支持撤销与重做。

普通滚轮平移，Shift+滚轮水平平移；图谱画布获得焦点时，+、- 分别缩放，0 执行 Fit。画布
平移不受滚动边界限制，折叠分支时保持所点击父卡片的屏幕位置；Fit 将可见树居中。搜索把手
描述当前实际展开状态，对搜索临时展开祖先的折叠操作仅在本次查询内生效，不改写原有折叠
意图。窄窗格工具栏自动换行，键盘焦点会显示屏幕外卡片。触摸支持空白画布单指平移、双指
捏合缩放和缩放按钮。

紧凑的“当前笔记”显示名称（完整路径见提示）与自动状态：跟随全局、已自定义 N 项或本笔记停用。虚拟编号、已写入编号显示与方案分别继承或覆盖；继承选项包含全局值。为「已写入编号」明确选择「隐藏」时，下方显示「隐藏范围」，默认「继承全局」。只有明确选择「隐藏」时，已保存的范围才计入自定义设置数。首次打开默认显示“显示与编号”，本次侧栏会话记住所选标签。标题栏的更多菜单可停用本笔记并保留配置，也可全部恢复全局。“起始与跳过”支持按需添加 H1–H9 规则。每张卡片的标题标明级别。H1 显示“起始编号”和“全篇跳过前几节”，H2–H9 还显示“每个父标题下跳过前几节”。帮助说明两种计数独立，命中任一项都会跳过整节及其全部子标题。“移除规则”清除本级所有覆盖并移除对应卡片。“修改正文”提供写入、重新编号和清理序号，移除标记与多文件操作位于下方。侧栏底部单独提供全局设置。正常已保存状态不额外占位，保存中、无效 YAML、冲突与保存错误明确可见。次要说明放入帮助提示，窄栏控件换行且不横向溢出。文件操作要求唯一匹配编辑器，否则失败关闭。

布局与展开深度放入次级“显示选项”，范围、搜索和缩放为主要工具。卡片采用轻边框、浅背景，虚拟与实体编号同时可见时并列独立胶囊，否则单独显示编号或中性层级，统一悬停、选中与焦点样式；移动按钮和落点仅在“调整结构”模式出现。

“跟随全局”删除对应 Property；“全部恢复”删除所有插件覆盖并保留其他 Properties。成功写入
Property 后，选项卡必须退出忙碌状态、重新读取 Properties，并立即刷新实时预览、阅读视图
与大纲。读取失败时禁止盲写并提供重试。单笔记修改 Markdown 的侧栏操作与命令统一在“修改正文”中打开逐项预览，固定目标文件名与变更数量，提供返回、取消和应用，保留警告与分段加载。目标与操作区保持可见，差异列表独立滚动。切换活动笔记或侧栏标签时，保留预览及原目标；过期预览拒绝后禁用应用，返回并重建预览后才能应用。返回、取消或应用成功后恢复“修改正文”的操作列表。批量选择和预览保留宽弹窗，方案编辑仍在全局设置。

<!-- section: settings-experience -->
## 全局设置体验

「链接与引用」在普通 Wiki 链接开关旁保留简短说明。引用教程列出适用目标、原生链接行为和排除情况。

设置统一分为七个选项卡：常规、标题编号、题注、链接与引用、脚注与尾注、写入与清理、显示与外观。批量操作的选项在写入与清理中。活动选项卡同时使用强调色下划线和半粗字重，选项卡基线与内容面板之间保留稳定间距。内置方案可
展开查看并复制为自定义方案。自定义方案必须
提供名称、起始层级、H1-H9 模板实时预览和精确排除列表。内置和自定义方案的预览统一显示
“编号胶囊＋本地化标题”，所有示例层级的计数值固定为 1，具体格式由模板决定（例如 1、一、
A、a、1.1），不改变笔记的实际起始值或编号规则。占位符示例直接解释 `{2.arabic}`，
不再出现不明含义的“→ 3”。空模板显示“该层级不编号”；非空模板语义错误时，保存按钮
不得提交，并显示可理解的约束说明。

频繁设置修改可以合并保存，但界面必须显示保存中、失败原因和重试入口。不能把未持久化值
显示成已保存。

当前笔记的数字输入在失焦或按 Enter 时才提交有效值；无效输入显示就地说明，不安排写入。
逐级编号控件可以展开。已提交但保存失败的草稿在切换笔记或面板后仍保留；重试只自动合并
互不冲突的设置修改。同一设置的不同修改必须展示双方值，并由用户明确决定是否应用草稿。
即使外部 Properties 无效，也始终提供放弃修改并重新加载的入口。

<!-- section: previews-and-warnings -->
## 预览与警告

批处理在同一个窗口中分两步进行。先选择文件夹或整个库，再选择操作并打开预览。范围和操作
初始均为空，窄窗口中上下排列。确认页显示范围、操作、排除文件夹后实际检查的 Markdown 笔记
数、将写入的笔记数、变更处数和警告数。“应用到 N 篇笔记”只计算源文会改变的笔记，零篇时
禁用。返回上一步会保留范围与操作，下次预览重新读取当前笔记内容。批量操作未能应用时保留预览并显示原因。文件已变化或回滚不完整时需要重新预览。若只是暂时失败且原文完好，可以直接重试。

当前笔记和批处理预览必须列出文件、行号、修改前后文本及警告。预览过期时整体
取消。歧义前缀、多重前缀、空标题、缺少父层或不支持的前缀必须解释为何未修改。实体操作
必须提醒标题链接风险。

每个文件使用原生折叠摘要，显示该文件的变更及警告数量。首次只展开第一个文件，其他文件在展开时才渲染内容；分页也以文件为单位。只突出编号变化的片段，未变的标题保持正常文字颜色，并保留“修改前/修改后”标签。

只有警告的文件仍进入预览，但不进入写入或恢复集合。变更和警告可以逐步展开直至查看全部
结果。正常诊断使用本地化原因，不直接显示内部规则标识。

<!-- section: display-behavior -->
## 显示行为

虚拟序号在视觉上位于标题文本之前，但不得进入复制文本或可编辑源范围。隐藏实体序号时，
光标或选择触及标题行应恢复实体文本；IME composition 期间只恢复当前标题的源码，其他标题
装饰继续显示。阅读视图在源码标题与渲染标题数量或层级不一致时不做部分猜测。

Live Preview 中，经过认证的 H7-H9 扩展行使用标题样式；仅当该行未被选择且没有 IME
composition 时隐藏井号标记。阅读视图只有在扩展行能映射为独立渲染段落时才将其作为标题，
否则该区块保持原样。Source Mode 默认保留可见扩展标记。界面文案必须说明这些层级属于
Number Suite/DocWen 扩展而非 Obsidian 原生标题，并建议用稳定块 ID 作为互通目标。

识别到的整条题注变成可换行实心胶囊；开启编号时在视觉上从 `Figure:` 变为 `Figure 1:`
（Table、Equation、Code 同理），但不修改源码。题注对齐独立于编号，四种固定类型分别具有居中开关；Figure 和 Equation 默认
居中，Table 和 Code 默认跟随主题。题注类型提供语义标签与计数器，相邻的独立图片、表格、块
公式或围栏代码块都可以成为承载对象。零或一个空行允许绑定；两个空行或任一侧有歧义时题注
保持未绑定。四种类型还可独立选择视觉上位于绑定对象上方或下方，默认均在上方；所有绑定题注
共用对象锚点和不受主题影响的紧凑间距。新题注写在对象上方，但显示绝不改写已有源码。光标
进入题注时在实际写入位置显示完整源码；Source Mode 始终显示 Markdown；光标进入引用时只
显示该引用自身的源码标记。触控和输入法编辑遵循同一局部显露规则，未编辑的题注和引用胶囊
继续显示。

编辑模式右键菜单为独立图片提供 Figure、为顶层 Markdown 表格任意行提供 Table、为独立块公式
提供 Equation、为顶层围栏代码块提供 Code；先解析真实指针目标，再回退到光标。Structural Tables 接管的表格菜单只有在文件、精确源码与视觉范围均验证后才提供相同操作。来源快照缺失或过期时显示停用说明，提示在源码模式编辑，不会回退到另一个表格序号。弹窗在可安全
推导时预填图片题名，展示将要
写入的精确题注预览，并在题名为空时禁用确认。所有新题注都放在对象上方；图片下方紧邻的旧
Figure 题注提供“移到上方”修复。附近只有关键词大小写错误时改为修正操作，已有任意类型题注时不
显示操作。行内和单元格里的图片、公式、代码不具备独立题注资格。创建题注绝不创建 ID。修正或移动题注时，它原有的行内与独立块 ID 会一起保留。

默认开启的图片/Figure 悬停设置在绑定图片和图题上显示同一结构化提示：先显示渲染图题，再显示
有效替换文字或 alt；相同内容合并为一行，尺寸参数和仅文件名回退不显示。行内及单元格图片只能
显示替换文字。

显式语义引用把完整视觉源码替换为可交互描边胶囊。胶囊显示别名或目标题名；目标存在可见
编号时带上编号，关闭编号后仍保持胶囊。标题名和完整类型化题注名在同文件内共同消歧；目标
缺失、重复、有歧义或跨文件时保持原样。单击或用键盘激活胶囊会跳到精确源码目标；IME
composition 期间或选择范围触及引用时，只恢复该引用的可编辑源码，不隐藏其他胶囊。插件清理
会恢复前导 `@`、原生链接文本、ARIA 与目标元数据。

标题/题注右键菜单只保留一个**复制交叉引用**操作。目标已有块 ID 时直接复制；没有时显示
聚焦的前后对比预览，确认后用一次过期校验事务在合法位置插入块 ID：题注行内、标题下一行。
其后再复制带可读别名的链接。不使用二级菜单，也不
自动迁移题名引用。

脚注显示为 `1、2、3`，尾注显示为 `E1、E2、E3`；两者在每个文件内分别按首次引用顺序
计算，重复引用复用首次序号。Live Preview 可选择格式化编号或原始标记；单击格式化编号或
把光标移到编号处，会展开可编辑的源码标记。阅读模式保留原生链接跳转。装饰只替换可见
引用/定义标签，保留 Obsidian 原生链接、列表结构和源码。定义缺失、重复、规范化冲突或
渲染节点数量不匹配时保持原样；重新处理或插件清理时恢复原有标签和列表值。

## 无障碍与移动端

虚拟标题序号和生成的题注序号应从辅助技术语义中隐藏，实体题注内容仍可访问；交叉引用胶囊
提供链接语义、可见文本、键盘焦点和不只依赖颜色的描边差异。格式化注释标签应提供注释
类型与编号。大纲行、折叠控件、思维导图卡片主体与可点击把手、以及操作按钮
必须具有清晰键盘焦点；粗指针设备上的可点击控件至少 44 像素高。思维导图不能只靠颜色表示
选中或搜索命中状态，零子标题把手不可伪装成可操作控件；摘要在窄屏可重排而不丢字段。模拟器结果不得表述为实体设备通过。

<!-- section: error-recovery -->
## 错误与恢复

设置保存失败保留待保存快照。批处理失败只回滚仍精确匹配插件写入结果的文件，并保留可用
恢复记录。并发编辑、损坏恢复数据或宿主渲染差异都应失败关闭，不能以成功提示掩盖未完成
工作。


长篇语法示例与教学说明以轻量原生 details 折叠，短提示、风险/错误始终外显。展开状态仅在设置窗口本次会话内保留；切换设置选项卡不丢失，关闭后重置。不将教学折叠状态保存到插件设置。链接与引用、显示与外观保持七页结构；批量参数移入写入与清理，常规的重置操作放在末尾。当前笔记“起始与跳过”无自定义规则时默认收起，有规则时自动展开并显示条数。

设置和当前笔记的帮助卡片使用淡主题色底和中性边框。标题前的小箭头使用主题强调色，整行可点，长标题可换行。键盘焦点清晰可见，触屏点击区域至少 44 CSS 像素高。教程展开后，正文起始侧有一条与箭头同色的细线。设置控件和操作警告保持常显。


### 实体编号与普通 Wiki 标题链接的显示规则

[进阶指南](advanced.zh-CN.md#实体编号与普通-wiki-标题链接的显示规则)说明已有标题编号的描边范围，以及它和虚拟编号、隐藏编号叠加时的表现。

普通同文件 Wiki 链接增强仍默认关闭。开启后，**只有目标标题实际显示虚拟编号**，才在原生链接前添加无焦点、不可独立点击的中性灰编号胶囊；不拿实体编号或 H 级别充当虚拟编号。显式 `|别名` 的原有文字完全保留，即便别名带数字也不去重。不带别名时，若启用了“隐藏已写入序号”，仅将可靠识别的实体前缀从链接**可见文字**中隐藏；链接目标、右键、修饰键点击、悬停及 Markdown 原文不变。实时预览和阅读模式共用这一规则；带路径但解析到当前文件的链接可以增强，跨文件、块链接和嵌入保持原生。无法可靠识别时不隐藏、不猜测。显式 `@[[...]]` 始终保留完整引用胶囊，不拆成左右两段。
