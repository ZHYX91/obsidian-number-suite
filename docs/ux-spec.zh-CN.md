# Number Suite — 交互规范

[English synced translation](ux-spec.en.md)

<!-- section: authority -->
## 文档权威性

本文是交互与文案行为的中文规范源；英文文件为同步译本。视觉截图和执行证据不覆盖本文。

<!-- section: principles -->
## 交互原则

- 始终区分源文件状态和 Obsidian 中的视觉状态。
- 任何文件修改必须先让用户看到逐项结果和风险。
- 默认选项应保守，歧义情况应保留原文并给出原因。
- 全局值、当前笔记覆盖值和最终生效值必须可区分。
- 移动端、窄窗口、键盘和触摸操作必须保持可达，不依赖悬停。

<!-- section: entry-points -->
## 入口

功能区图标打开常驻右侧栏，并保留上次选择的选项卡。“打开 Number Suite 大纲”命令直接
选择“文档大纲”，“打开当前笔记控制面板”直接选择“当前笔记”。命令面板还提供恢复源样式、
独立切换虚拟显示/隐藏、当前笔记写入/清理/重新编号、移除来源标记、批处理和撤销最近批处理。
没有活动 Markdown 笔记时，当前笔记操作不可执行并显示明确提示。

<!-- section: current-note-panel -->
## Number Suite 侧栏

侧栏包含“文档大纲”和“当前笔记”两个内部选项卡；新建侧栏默认显示文档大纲。文档大纲跟随
活动 Markdown 笔记，按层级显示原生 H1-H6、Number Suite/DocWen H7-H9 扩展标题，以及
Figure/Table/Equation/Code 题注。它与编辑器共用当前笔记最终生效的编号与隐藏计划，从标签中
去掉用户写入的块 ID，支持章节折叠，并按源码行跳转而不改写 Markdown。题注归入其前方最深
标题；标题前的题注作为根条目。

两个侧栏选项卡等宽并横跨侧栏，以弱化文字表示未激活状态，以半粗文字和底部强调色线表示
激活状态；悬停使用轻量背景，键盘焦点使用不覆盖激活线的清晰内描边。选项卡采用
`tablist`、`tab`、`tabpanel`、`aria-controls`、`aria-labelledby` 和 roving tabindex，支持
Left/Right、Home、End，RTL 下按视觉方向移动，并在切换后保持活动选项卡可见且获得焦点。

“当前笔记”先显示笔记名称和路径，再用“设置项 / 全局值 / 当前笔记覆盖 / 最终生效值”摘要
呈现虚拟显示、实体隐藏、方案和完全忽略。显示与隐藏均使用“跟随全局 / 开启 / 关闭”三态。
方案下拉只展示可用名称，不要求用户输入内部 ID。侧栏获得焦点后，文件操作仍应解析该笔记
唯一打开的编辑器；没有匹配编辑器或同一笔记存在多个编辑器时必须失败关闭。

当前笔记内容使用轻量分组面承载每组生效值，以弱化的小节标题、留白和最终值强调建立层级，
不堆叠整行分隔线。说明卡在侧栏中使用无强调色边框的紧凑样式；读取状态使用带文字的独立
状态指示器，并在减少动态效果偏好下停止旋转。

“跟随全局”删除对应 Property；“全部恢复”删除所有插件覆盖并保留其他 Properties。成功写入
Property 后，选项卡必须退出忙碌状态、重新读取 Properties，并立即刷新实时预览、阅读视图
与大纲。读取失败时禁止盲写并提供重试。修改 Markdown 的操作仍使用独立逐项预览弹窗；批量
范围选择和全局设置仍是独立目标。

<!-- section: settings-experience -->
## 全局设置体验

设置统一分为七个选项卡：常规、标题编号、题注、交叉引用、脚注与尾注、写入与清理、显示与批处理。活动选项卡同时使用强调色下划线和半粗字重，选项卡基线与内容面板之间保留稳定间距。内置方案可
展开查看并复制为自定义方案。自定义方案必须
提供名称、起始层级、H1-H9 模板实时预览和精确排除列表。空模板显示“该层级不编号”；非空
模板语义错误时，保存按钮不得提交，并显示可理解的约束说明。

频繁设置修改可以合并保存，但界面必须显示保存中、失败原因和重试入口。不能把未持久化值
显示成已保存。

<!-- section: previews-and-warnings -->
## 预览与警告

当前笔记和批处理预览必须列出文件、行号、修改前后文本、识别来源及警告。预览过期时整体
取消。歧义前缀、多重前缀、空标题、缺少父层或不支持的前缀必须解释为何未修改。实体操作
必须提醒标题链接风险。

<!-- section: display-behavior -->
## 显示行为

虚拟序号在视觉上位于标题文本之前，但不得进入复制文本或可编辑源范围。隐藏实体序号时，
光标或选择触及标题行应恢复实体文本，IME composition 期间应撤销装饰。阅读视图在源码标题
与渲染标题数量或层级不一致时不做部分猜测。

Live Preview 中，经过认证的 H7-H9 扩展行使用标题样式；仅当该行未被选择且没有 IME
composition 时隐藏井号标记。阅读视图只有在扩展行能映射为独立渲染段落时才将其作为标题，
否则该区块保持原样。Source Mode 默认保留可见扩展标记。界面文案必须说明这些层级属于
Number Suite/DocWen 扩展而非 Obsidian 原生标题，并建议用稳定块 ID 作为互通目标。

识别到的整条题注变成可换行实心胶囊；开启编号时在视觉上从 `Figure:` 变为 `Figure 1:`
（Table、Equation、Code 同理），但不修改源码。题注对齐独立于编号，四种固定类型分别具有居中开关；Figure 和 Equation 默认
居中，Table 和 Code 默认跟随主题。题注类型提供语义标签与计数器，相邻的独立图片、表格、块
公式或围栏代码块都可以成为承载对象。零或一个空行允许绑定；两个空行或任一侧有歧义时题注
保持未绑定。四种类型还可独立选择视觉上位于绑定对象上方或下方，默认均在上方；所有绑定题注
共用对象锚点和不受主题影响的紧凑间距。新题注写在对象上方，但显示绝不改写已有源码。光标
进入题注时在实际写入位置显示完整源码；Source Mode 始终显示 Markdown；光标进入引用时只
显示该引用自身的源码标记。

编辑模式右键菜单为独立图片提供 Figure、为顶层 Markdown 表格任意行提供 Table、为独立块公式
提供 Equation、为顶层围栏代码块提供 Code；先解析真实指针目标，再回退到光标。Structural Tables 接管的渲染表格菜单也会
得到同一“添加表名”操作，并在显示弹窗前解析包含全部连续表头行的完整源码范围。弹窗在可安全
推导时预填图片题名，展示将要
写入的精确题注预览，并在题名为空时禁用确认。所有新题注都放在对象上方；图片下方紧邻的旧
Figure 题注提供“移到上方”修复。附近只有关键词大小写错误时改为修正操作，已有任意类型题注时不
显示操作。行内和单元格里的图片、公式、代码不具备独立题注资格。创建题注绝不创建 ID。

默认开启的图片/Figure 悬停设置在绑定图片和图题上显示同一结构化提示：先显示渲染图题，再显示
有效替换文字或 alt；相同内容合并为一行，尺寸参数和仅文件名回退不显示。行内及单元格图片只能
显示替换文字。

显式语义引用把完整视觉源码替换为可交互描边胶囊。胶囊显示别名或目标题名；目标存在可见
编号时带上编号，关闭编号后仍保持胶囊。标题名和完整类型化题注名在同文件内共同消歧；目标
缺失、重复、有歧义或跨文件时保持原样。单击或用键盘激活胶囊会跳到精确源码目标；IME
composition 期间或选择范围触及引用时恢复可编辑源码。插件清理会恢复前导 `@`、原生链接文本、
ARIA 与目标元数据。

标题/题注右键菜单只保留一个**复制交叉引用**操作。目标已有块 ID 时直接复制；没有时显示
聚焦的前后对比预览，确认后用一次过期校验事务在合法位置插入块 ID：题注行内、标题下一行。
其后再复制带可读别名的链接。不使用二级菜单，也不
自动迁移题名引用。

脚注显示为 `1、2、3`，尾注显示为 `E1、E2、E3`；两者在每个文件内分别按首次引用顺序
计算，重复引用复用首次序号。Live Preview 可选择格式化编号或原始标记；单击格式化编号或
把光标移到编号处，会展开可编辑的源码标记。阅读模式保留原生链接跳转。装饰只替换可见
引用/定义标签，保留 Obsidian 原生链接、列表结构和源码。定义缺失、重复、规范化冲突或
渲染节点数量不匹配时保持原样；重新处理或插件清理时恢复原有标签和列表值。

<!-- section: accessibility-and-mobile -->
## 无障碍与移动端

虚拟标题序号和生成的题注序号应从辅助技术语义中隐藏，实体题注内容仍可访问；交叉引用胶囊
提供链接语义、可见文本、键盘焦点和不只依赖颜色的描边差异。格式化注释标签应提供注释
类型与编号。侧栏选项卡、大纲行、折叠控件和操作按钮必须对齐一致、具有键盘焦点，并在粗
指针设备上至少 44 像素高；摘要在窄屏可重排而不丢字段。模拟器结果不得表述为实体设备通过。

<!-- section: error-recovery -->
## 错误与恢复

设置保存失败保留待保存快照。批处理失败只回滚仍精确匹配插件写入结果的文件，并保留可用
恢复记录。并发编辑、损坏恢复数据或宿主渲染差异都应失败关闭，不能以成功提示掩盖未完成
工作。
